## 3. 0-20 级详细攻略

- **阶段目标**：完成新手流程，解锁师门入口。
- **推荐等级**：20（够做师门即可，不需冲）。
- **是否停级**：否。
- **主要升级方式**：主线 + 新手任务（经验海量）。
- **主要赚钱方式**：无（纯投入期），靠任务奖励变现。
- **必做**：主线、新手引导、门派拜师、新区开服冲级活动。
- **可选**：师徒任务、新手礼包。
- **不建议**：抓鬼/副本（怪强经验少、耗时）、过早配装备。
- **推荐活动**：新区开服活动（有送经验/元宝）。【需验证】
- **推荐副本**：无（未开放）。
- **推荐日常**：主线任务。
- **装备要求**：系统/新手装。
- **技能要求**：点师门输出技能 + 1个辅助。
- **修炼要求**：无。
- **宠物要求**：系统送的够用。
- **现金储备**：0（不需要）。
- **五开需求**：只练主号，其余4号建好丢着吃新区奖励。
- **下阶段进入条件**：主号到20级 + 完成入门拜师。

## 4. 20-40 级详细攻略

- **阶段目标**：快速冲40解锁五开核心。
- **推荐等级**：40。
- **是否停级**：否。
- **主要升级方式**：师门（每天必做，稳定）+ 剧情 + 跑环【需验证】。
- **主要赚钱方式**：师门现金 + 卖掉落。
- **必做**：师门、主线剧情。
- **可选**：跑环、擂台。
- **不建议**：高等级副本（装备未成型）、配成品宝宝。
- **推荐活动**：日常活动。
- **推荐副本**：低级剧情副本（若有）。
- **推荐日常**：师门（五开同做）。
- **装备要求**：系统/环装，别花钱。
- **技能要求**：主输出技能满（当前等级上限）。
- **修炼要求**：可不点，或点攻/法修1-2级。
- **宠物要求**：低资质过渡宠。
- **现金储备**：10-30万（攒着别乱花）。
- **五开需求**：此时应启动5号，统一做师门/主线，等级拉平。
- **下阶段进入条件**：5号到40级。

## 5. 40-60 级详细攻略

- **阶段目标**：正式五开成型，稳定刷师门/抓鬼/封妖。
- **推荐等级**：60。
- **是否停级**：否（快速到69）。
- **主要升级方式**：师门 + 抓鬼 + 剧情。
- **主要赚钱方式**：师门现金 + 抓鬼/封妖掉落。
- **必做**：师门、抓鬼、封妖。
- **可选**：日常活动、帮派任务。
- **不建议**：买成品装备/宝宝（过渡期）。
- **推荐活动**：新区活动（前期收益高）。
- **推荐副本**：低级副本。
- **推荐日常**：师门 + 抓鬼 + 封妖。
- **装备要求**：60环装（自己刷最划算）。
- **技能要求**：主输出技能 + 关键辅助技能。
- **修炼要求**：攻/法修点到5左右（低成本阶段）。
- **宠物要求**：每号一只过渡攻宠。
- **现金储备**：50-100万。
- **五开需求**：五开必须成型，统一等级。
- **下阶段进入条件**：5号到60级。

## 6. 60-69 级详细攻略（第一停级点）

- **阶段目标**：停在69沉淀，攒钱补技能/修炼。
- **推荐等级**：69（停级）。
- **是否停级**：**是（过渡停级，不建议长期死停）**。
- **主要升级方式**：停级，不再冲级。
- **主要赚钱方式**：师门 + 封妖 + 抓鬼 + 活动。
- **必做**：师门、封妖、抓鬼。
- **可选**：日常活动、挖宝。
- **不建议**：高难度副本（69门槛低难进）、买成品装。
- **推荐活动**：周末活动（69可参与的部分）。
- **推荐副本**：69能进的最低级副本。
- **推荐日常**：师门 + 封妖 + 抓鬼。
- **装备要求**：70简易（武器高伤优先）+ 60环装混合。
- **技能要求**：主输出技能 + 修炼（要开始投钱的地方）。
- **修炼要求**：攻/法修 + 双防（点到新区成本可接受即止）。
- **宠物要求**：每号一只攻宠（关键投入点）。
- **现金储备**：100-200万周转。
- **五开需求**：五开成型，纯固伤最佳。
- **下阶段进入条件**：69沉淀完成、修为到位、资金充裕。

## 7. 70-89 级详细攻略

- **阶段目标**：评估是否突破69。
- **推荐等级**：视投入（多数建议跳过89直上109）。
- **是否停级**：建议不停（作为过渡）。
- **主要升级方式**：师门 + 抓鬼 + 副本。
- **主要赚钱方式**：师门 + 抓鬼 + 副本产物。
- **必做**：师门、抓鬼。
- **可选**：侠士副本。
- **不建议**：过度投入89装备（性价比不如109）。
- **推荐活动**：日常 + 周末。
- **推荐副本**：90前后开放的侠士本。
- **推荐日常**：师门 + 抓鬼。
- **装备要求**：环装过渡，不重投入。
- **技能要求**：随等级补满。
- **修炼要求**：继续补攻/法修。
- **宠物要求**：过渡攻宠。
- **现金储备**：200-400万。
- **五开需求**：五开持续。
- **下阶段进入条件**：资金足、准备上109。

## 8. 90-109 级详细攻略（主搬砖停级点）

- **阶段目标**：109长期停级，稳定高效搬砖。
- **推荐等级**：109（停级）。
- **是否停级**：**是（主停级点）**。
- **主要升级方式**：停级，靠日常/副本积累。
- **主要赚钱方式**：师门 + 抓鬼 + 封妖 + 侠士副本 + 周末活动 + 挖宝。
- **必做**：师门、抓鬼、封妖。
- **可选**：侠士副本、挖宝、跑商。
- **不建议**：过度追求高难度（收益未必值投入）。
- **推荐活动**：周末活动（收益最高）。
- **推荐副本**：109全开副本。
- **推荐日常**：师门 + 抓鬼 + 封妖 + 每周副本。
- **装备要求**：100任务装/简易，属性达标即可。
- **技能要求**：主输出 + 辅助满。
- **修炼要求**：攻/法修 + 双防重点投入（性价比最高）。
- **宠物要求**：全队攻宠 + 主号血宠。
- **现金储备**：500万+。
- **五开需求**：五开成熟，收益/投入比最优。
- **下阶段进入条件**：109收益已瓶颈、预算充足再上探。

## 9-11. 110-129 / 130-159 / 160-175 详细攻略

**110-129**：开放神器、高难度副本，收益提升但装备宝宝修炼全面提升；适合109成型后突破。**【需验证】具体收益**。
**130-159**：接近半成品号打工，投入产出比开始下降，**性价比转入下行**。
**160-175**：收益上限但投入可能是109的数十倍，**回本周期极长**【需验证】，普通搬砖不建议硬上。

**通用结论**：129是性价比之王（相对）、175是收益天花板（对应高投入）。逐级上探前务必用「§18b 升级/停级决策系统」算清回本周期。
