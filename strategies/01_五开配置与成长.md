## 12. 五开门派组合

### 低投入五开（预算 < 500 元级）

**推荐：2 无底洞 + 普陀山 + 女儿村 + 阴曹地府**（纯固伤体系）

| 维度 | 评价 |
| --- | --- |
| 输出效率 | 中（固伤不依赖武器高伤，下限高） |
| 生存能力 | 高（无底洞奶+女儿封） |
| 蓝耗 | 低 |
| 装备成本 | **最低**（环装+70简易即可） |
| 宝宝成本 | 低（攻宠） |
| 修炼成本 | 低（可只点攻/法修） |
| 任务覆盖率 | 高（师门抓鬼封妖都行） |
| 操作难度 | 低（几乎挂机） |
| 新区适应性 | **强** |
| 搬砖能力 | 中（胜在稳定低成本） |

### 平衡五开（预算 1000-2000 元级）

**推荐：无底洞 + 普陀山 + 女儿村 + 魔王寨 + 凌波城**（固伤 + 法 + 物混合）

优点：任务覆盖更广（能打高难度活动），输出更快。
缺点：凌波城宝宝/装备成本上升，操作需留意。

### 高效率五开（预算 3000+ 元级）

**推荐：女儿村 + 普陀山 + 地府 + 化生寺 + 魔王寨**（封辅法混搭）

优点：效率极高，能平推多数副本与活动，搬砖小时收益最高。
缺点：投入大，宝宝/装备/修炼都要到位。

**通用取舍**：新区前期建议**纯固伤**（成本最低、成型最快、最稳）；资金充裕再补法系/物理提升效率。

## 13. 五开装备成长路线

**新手装备 → 环装 → 基础装备 → 任务装备 → 成品装备**

| 阶段 | 装备 | 建议 |
| --- | --- | --- |
| 0-40 | 系统/新手装 | 别花钱 |
| 40-69 | 环装 | 自己刷/买最便宜，能用即可 |
| 69 停级 | 70 简易 + 60 环装 | 武器优先高伤，防具次要 |
| 90-109 | 100 任务装备/简易 | 开始投入，属性达标即可 |
| 129+ | 高属性成品 | 成本高，量力 |

**原则**：装备是「消耗品」，新区掉价快；**修炼是「沉淀资产」**。前期钱优先修炼、技能、宝宝，装备够用就行。

## 14. 五开宝宝成长路线

**系统宝宝 → 过渡宝宝 → 任务宝宝 → 成品宝宝**

| 阶段 | 宝宝 | 建议 |

## 15. 技能/修炼/法宝优先级（钱先花哪）

**优先级排序（高到低）**：

1. **主输出技能**（决定刷怪效率，最优先）
2. **人物基础修炼**（攻/法修 → 双防）
3. **宝宝技能 + 宝宝资质**（抓鬼封妖核心战力）
4. **次级技能**（辅助/生存技能，够用即止）
5. **法宝**（【需验证】对搬砖的实际增益，锦上添花）
6. **成品装备/高价值宝宝**（最后，且视资金）

**一句话**：先把「刷得快」的钱花了（技能+修炼+攻宠），再考虑「刷得爽」的钱（法宝+成品装）。

## 18. 新区资金管理

**0 资金 → 100 万 → 500 万 → 1000 万 → 成型五开**

| 资金阶段 | 主要用途 |
| --- | --- |
| 0-100 万 | 全留给技能 + 修炼，别买装备 |
| 100-500 万 | 补修炼 + 每人一只攻宠 + 环装 |
| 500-1000 万 | 拉平全队装备到 70 简易 + 提升宝宝 |
| 1000 万+ | 考虑上探 109 或补高价值装备 |

**100 万资金分配示例**：
- 修炼 40%
- 技能 20%
- 宝宝 20%（攻宠）
- 环装/周转 15%
- 预留 5% 应急

> 注：具体占比受新区物价影响，需实测调整。

## 19. 搬砖收益模型

**公式**：
**小时收益 = 现金收益 + 物品出售收益 + 其他可变现收益 − 消耗成本（点卡/药/装备折旧）**

**日收益 = 小时收益 × 游玩小时数**
**周收益 = 日收益 × 7（含周末加成）**

> ⚠️ **重要声明**：以上具体金额**不做虚构**。
> **「该数据需要根据当前新区、服务器、物价和实际测试重新测算。」**
> 这是因为收益高度依赖：新区稀缺度、物价波动、队伍成型度、活动档期、点卡成本。

建议用本项目的任务状态机 + 记忆系统（已完成）实测记录真实收益，再回填模型。
