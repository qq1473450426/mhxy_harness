# 梦幻西游 五开本地 AI 自动任务系统

> 一整套「新区练号 → 五开 → 搬砖」攻略 + 自动任务系统。
> **新手友好：不用敲命令，双击一键启动，浏览器点鼠标操作。**

## 快速开始（小白看这里）

### 方法一：一键启动（推荐）

双击 **`start.bat`**（在项目根目录 `D:\Deepseek\mhxy`），它会自动：
1. 启动 Web 作战台
2. 浏览器自动打开 `http://127.0.0.1:8080`

之后所有操作都在网页上：
- 点击「启动自主游戏」→ 系统自动监测游戏
- 点击「训练优化」→ 强化学习优化策略
- 每个账号卡片可「人工接管 / 恢复自动」
- 页面实时显示：队伍状态 / 推荐任务 / 五开里程碑 / 账号截图

> 新手建议只用 Web 作战台（`start.bat`）。

### 方法二：只读巡检（可选）

要看当前游戏画面（不操作游戏），可运行：

    python app.py --scan      # 看当前画面 + 状态识别
    python app.py --manual    # 一站式作战卡片(账号+攻略+阵容+任务)

## 项目是什么

**三大能力：**
1. **攻略**：新区 0→175 级完整成长路线、五开门派组合、任务优先级、资金与收益模型。
2. **看**：能识别游戏画面（登录/选服/排队/选角/游戏内），实时读到角色/等级/门派/任务。
3. **自动**：完整自主游戏闭环（启动→监控→任务→结束）+ 强化学习优化 + 五开协调。

> 系统把「游戏知识库」「本地 AI 决策」「视觉识别」「鼠标键盘控制」组合成闭环。

## Web 作战台功能

打开 `http://127.0.0.1:8080` 后：

| 区域 | 功能 |
| --- | --- |
| 顶部状态栏 | 自主游戏阶段 / 是否运行 / 优化成功率 / 接管账号 |
| 控制按钮 | 启动 / 停止 / 训练优化 / 整体接管 |
| 队伍状态 | 队长 / 备用队长 / 当前任务 / 同步数 |
| 推荐任务 | 按你当前等级推荐最值得做的任务(S/A/B) |
| 五开里程碑 | 第1天→90天成长路线 |
| 账号卡片 | 每个号的角色/等级/状态/地图 + 接管/恢复按钮 + 截图 |

## 关键文件

| 文件 | 说明 |

## 重要提示（必读）

1. **登录需手动**：系统能「看」画面，但**不代你登录游戏**（账号密码/扫码需你自己操作）。
2. **封号风险**：《梦幻西游》严打脚本，真实自动执行任务有**封号风险**且违反用户协议。系统默认「只读/安全模式」（dry-run），**不会自动真跑任务**。
3. **收益数据**：攻略里的收益数字需你在游戏里**实测填入**，系统不虚构。
